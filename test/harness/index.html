Give me a short plan to move a small Postgres database to a new server with little downtime.

Set up the new server. Install the same Postgres major version on the new server. Copy the configuration files, the users and the network rules, and check each one.

Start a baseline copy. Use pg_basebackup to put a full copy of the database on the new server. The old database keeps running while the copy is made.

Catch up with replication. Set up streaming replication from the old server to the new one. Wait until the replication lag is a few seconds or less.

Cut over in a short pause. Stop the application writes and wait for the replica to catch up. Then point the application at the new server. The downtime is usually one to five minutes.
